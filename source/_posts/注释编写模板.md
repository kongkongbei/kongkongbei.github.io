## 类成员名称
以矩形形类为例,其包含的信息如下：左上角坐标点，高，宽，线宽，线性变换函数，则其命名要求如下。
类名称以大写开头
成员变量以"m_"开头，采用小驼峰匈牙利命名法
小函数采用小驼峰命名法
大函数采用大驼峰命名法
```cpp
class Rectangle
{
    public:
        Rectangle();
        ~Rectangle();
        void getPos();
        void LinearTrans();

    private:
        int m_iPosX, m_iPosY;
        int m_iHeight, m_iWight;
        void drawRect();
        void setRect();
}
```

## 函数注释
格式如下：
```cpp
/* 
*  描述：该函数功能为修改坐标位置
*  输入参数：X - x坐标 Y - y坐标
*  返回值：cX - 修改后的x坐标 cY - 修改后的y坐标
*/
```
```py
'''
描述：该函数功能为修改坐标位置
输入参数：X - x坐标 Y - y坐标
返回值：cX - 修改后的x坐标 cY - 修改后的y坐标
'''
```
